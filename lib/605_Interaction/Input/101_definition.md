## 1. Purpose

The `Input` subdomain defines modality-independent and device-independent representations of raw interaction stimuli generated by an Actor.

## 2. Core Concepts

### 2.1 Input
An **Input** is an atomic or sampled interaction stimulus originating from a physical device, virtual interface, or agent channel. Modalities include:
- Pointer (mouse, stylus, cursor);
- Touch (single-touch, multi-touch);
- Spatial (3D spatial controller, hand tracking, body tracking);
- Voice / Audio;
- Gaze;
- Semantic Command (agent or programmatic invocation).

### 2.2 Pointer
A **Pointer** is an interaction entity that identifies a spatial position or directional vector within a declared coordinate system, associated with active states (hover, press, drag, release).

### 2.3 Device Independence (`INT-002`)
Input events must not expose proprietary hardware structures or vendor-specific API assumptions into the semantic layer.

## 3. Invariants
- `INT-002` (Device Independence): Input semantics remain invariant across physical mouse, pen, touch, VR controller, or programmatic sources.
- `INT-003` (Gesture Distinction): Raw Input is distinct from Gesture ($\text{Input} \ne \text{Gesture}$).
