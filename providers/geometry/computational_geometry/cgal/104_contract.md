## 1. Contract Overview

This document specifies the concrete Provider Contract implemented by the `cgal` provider for the `geometry/computational_geometry` capability domain. It defines 2D/3D triangulation, convex hull computation, and polygon algorithms for geometric manifolds, simplicial complexes, and morphological analysis.

---

## 2. Semantic Capabilities

* `[geometry, triangulation, delaunay2d]` — 2D Delaunay Triangulation preserving empty circumcircles.
* `[geometry, convexhull, 2d]` — 2D Convex Hull computation in counter-clockwise order.
* `[geometry, polygon, point_in_polygon]` — Robust point in polygon inclusion test.
* `[geometry, polygon, area]` — Exact signed polygon area computation.

---

## 3. Operations & Signatures

* `cgal_delaunay_triangulation_2d(points, num_points, out_triangles, max_triangles, out_triangle_count) -> int`
* `cgal_convex_hull_2d(points, num_points, out_hull_indices, max_hull_indices, out_hull_count) -> int`
* `cgal_point_in_polygon_2d(polygon_vertices, num_vertices, query_point) -> int`
* `cgal_polygon_area_2d(polygon_vertices, num_vertices, out_area) -> int`

---

## 4. Preconditions & Postconditions

1. **Precondition (Input Size):** Convex hull and triangulation require at least 3 points. Violations return `CGAL_ERR_INSUFFICIENT_POINTS`.
2. **Precondition (Pointers):** All input array pointers and output capacity buffers must be non-null.
3. **Postcondition (Empty Circumcircle):** Every triangle generated by Delaunay triangulation must contain no input point in its circumcircle interior.
4. **Postcondition (Convexity):** The computed convex hull vertices form an oriented, strictly convex simple polygon enclosing all points.

---

## 5. Failure Semantics & Error Codes

* `CGAL_SUCCESS = 0`
* `CGAL_ERR_NULL_POINTER = -1`
* `CGAL_ERR_INSUFFICIENT_POINTS = -2`
* `CGAL_ERR_DEGENERATE_INPUT = -3`
* `CGAL_ERR_COMPUTATION_FAILED = -4`
