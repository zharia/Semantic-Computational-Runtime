# State

A semantically meaningful configuration of a field or entity at a point in the relevant state space.

## Semantic authority

This entry establishes foundational vocabulary. Domain-specific semantics belong in `lib/` definitions.

## Implementation independence

The definition does not prescribe a programming language, memory representation, provider, hardware target or execution mechanism.
