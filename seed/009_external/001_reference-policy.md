# External Reference Policy

External documentation is structured evidence and interoperability context.

It is never automatically Semantic Authority.

## Authority tiers

0. SCR normative semantics
1. Lean/Mathlib formal foundations
2. External normative standards
3. Foundational technical specifications
4. Academic literature
5. Implementation documentation

## Required reference metadata

```yaml
id:
authority:
title:
type:
version:
revision:
publication_date:
url:
stable_identifier:
relevant_section:
concepts:
relationship:
authority_over_scr: false
retrieved:
```

## Relationship vocabulary

- `informs`
- `supports`
- `motivates`
- `implements`
- `maps-to`
- `constrains-interoperability`
- `exactly-equivalent` (only with evidence)
- `closely-equivalent` (only with evidence)
- `broader`
- `narrower`
- `related`

Never claim equivalence merely because two terms have similar names.
