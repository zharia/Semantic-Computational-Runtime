# Kernel Reconciliation Record

STC was reviewed against the five-type kernel.

## Absorbed
State absorbs semantic configuration/hypergraph structure. Outcome carries result
state/context, removing primitive ResultState. Identity/entity/value/relationship are
structures within State. Observation is the semantic distinction boundary.

## Derived
Applicability, admissibility, constraints, transition, composition, atomicity, causality,
independence, concurrency, ordering, equivalence, provenance, persistence, migration,
replication, refinement and semantic space.

## Specializations
Deterministic step, rollback failure, failure-preserves-time, discrete logical step,
minimal context, CRUD HyperOp and node observation.

## Richer transition semantics
Nondeterminism, partiality, stochasticity and non-transactional failure can be modeled as
derived transition relations/extensions and do not currently justify a sixth primitive.

No STC concept currently demonstrates a need for a sixth fundamental semantic type.
This remains falsifiable by concrete counterexample.
