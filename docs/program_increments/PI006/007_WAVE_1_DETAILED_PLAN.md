# Wave 1 Detailed Plan

## Core
Expose stable domain-facing APIs for identity, value, entity, relationship, state,
context, transformation, outcome, observation and constraints.

## Mathematics / Foundations
Logic: proposition, predicate, truth value, expression; evaluate/substitute/simplify/compose.
Sets: membership, subset, union, intersection, difference, product.
Relations: domain, codomain, image, inverse.
Functions: domain, codomain, mapping, apply, compose, restrict.
Arithmetic: exact semantic arithmetic where practical.

## Data
Scalar, vector, matrix, sequence, set, map, tensor, collection. Separate semantic shape,
element type and value from storage layout and allocation.

## Graph
Graph, directed graph, multigraph, weighted graph, hypergraph. Add/remove/update,
traversal, subgraph, composition; observe node values, incidence, degree, paths,
connectivity and structure.

## Integration demonstrations
Matrix transformation, graph transformation, function application, mathematical relations
as graph structures, observational distinction/equivalence, and explicit failure.

## Negative tests
Invalid dimensions, incidence, function application, set operation, composition,
identity violation, dangling relationship, conflicting transformation, observation mismatch.
