# Acceptance Gates

## Kernel
One canonical kernel; no duplicate ontology; authoritative definitions; explicit
specialization boundaries.

## Domain
Specification, status and graph exist; dependencies resolve; structures, transformations,
constraints, observations and laws are defined; implementation maps to semantics.

## Formal
Lean builds; no unexplained `sorry`; declared laws have witnesses where required;
counterexamples remain represented.

## Implementation
Mojo builds; tests and negative tests pass; semantic outcomes are not replaced by physical
exceptions.

## Integration
Cross-domain composition works; domain graph is valid; no unjustified kernel primitive.

## Completion
Only mark COMPLETE when every required gate passes. Never substitute percentages,
line counts, test counts, compilation or agent assertions for semantic evidence.
