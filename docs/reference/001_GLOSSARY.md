# SCR Glossary

| Term | Meaning |
|---|---|
| Semantic Field | Foundational substrate in which semantic entities, relationships, transformations and contexts exist and evolve. |
| Entity | A semantically identifiable participant in the field. |
| Relationship | First-class semantic connection among field elements. |
| Transformation | A mapping that evolves semantic state or structure. |
| Topology | Meaningful pattern of connectivity and adjacency in the field. |
| Representation | A manifestation of semantic structure in a chosen form. |
| Provider | An implementation that satisfies a semantic contract. |
| Execution | Realisation of semantic transformations on resources. |
| Capability | A contract describing valid participation in an operation or relationship. |
| Constraint | A condition that restricts valid field states or transformations. |
| Observation | A projection of semantic state into an observable form. |
| Reference | A semantic association to another field element or region. |
| Resource | Physical capacity used to manifest execution. |
| Semantic identity | Identity defined independently of physical representation or location. |
| Quantisation | Deliberate reduction of numerical precision/range under an error contract. |
| Normalisation | Transformation to a canonical semantic form. |
| Manifestation | Physical or representational realisation of semantic structure. |
| Provider substitution | Replacement of one implementation by another satisfying the same semantic contract. |
| Semantic program | A substructure of the Semantic Field describing transformations and constraints. |
