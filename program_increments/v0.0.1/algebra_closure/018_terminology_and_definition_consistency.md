A term has one semantic meaning unless explicitly qualified.

## Special distinctions

### Transformation versus transition

Do not use these interchangeably unless formally shown equivalent.

### Outcome versus state

An outcome is not merely a state.

### Failure versus unchanged state

A failure is not a no-op unless the algebra explicitly defines them as equivalent.

### Entity versus identity

An entity is not its identity.

### Relationship versus pointer

A relationship is semantic.

### State versus representation

A representation is not semantic authority.

### Semantic time versus machine integer

A machine integer may represent semantic time but is not semantic time by default.

### Capability versus provider

A capability is semantic possibility/contract; a provider is a physical implementation.

### Manifestation versus execution

Manifestation is the realization boundary; execution is one possible manifestation process.
