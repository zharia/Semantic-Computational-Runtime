# 010 — Space and Semantic Machine

## Space layers

Explicitly distinguish:

1. semantic space;
2. computational space;
3. physical space.

## Semantic space

Define whether semantic space is:

- a relation;
- topology;
- metric;
- hierarchy;
- graph;
- coordinate system;
- contextual structure.

Do not assume physical coordinates are semantic location.

## Computational space

Define computational regions with:

- identity;
- semantic state;
- execution context;
- transformation capability;
- resources;
- relationships;
- containment.

## Physical space

Physical location includes:

- process;
- machine;
- device;
- memory;
- network;
- storage.

These are manifestations unless the semantic contract explicitly promotes a property.

## Location

Define semantic location independently from memory address.

## Movement

Distinguish:

- semantic movement;
- migration;
- representation relocation;
- physical data movement.

## Containment

Define whether semantic containment is:

- hierarchical;
- graph-based;
- contextual;
- temporal.

## Space transformation

Determine whether movement can change identity, context, relationships, or equivalence.

## SMM closure

The Semantic Machine Model must be derived from the closed algebra, not become a second competing ontology.
