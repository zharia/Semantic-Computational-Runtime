# Sprint 01: Elastic Continuum & Lamé Parameter Derivation

## 1. Objectives
Derive continuum elastic moduli $(K, G, \lambda, \mu)$ and acoustic wave velocities $(v_p, v_s)$ from SCR physical contracts $(E, \nu, \rho)$.

## 2. Invariants
- For solids: $E > 0$, $0 \le \nu < 0.5$, $\rho > 0$.
- $v_p = \sqrt{(\lambda + 2\mu)/\rho} > v_s = \sqrt{\mu/\rho} > 0$.
