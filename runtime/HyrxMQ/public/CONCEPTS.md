# Concepts

## Hyrx

The messaging engine.

## HyrxMQ

The standalone broker product.

## Message

A unit of application communication.

## Endpoint

A logical source or destination.

## Route

The mechanism that determines delivery destinations.

## Transport

The mechanism used to physically move or hand off a message.

## AMQP

A compatibility protocol exposed by HyrxMQ.

The important distinction is:

> **Hyrx semantics are not the same thing as AMQP wire representation.**
