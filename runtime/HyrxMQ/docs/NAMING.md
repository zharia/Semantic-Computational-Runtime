# Naming

## Canonical names

- Hyrx — core technology and messaging engine
- HyrxMQ — standalone broker product
- `hyrxmq` — executable/service identifier

## Usage

Prefer:

> Hyrx Core

> Hyrx Embedded

> Hyrx Local

> Hyrx Network

> HyrxMQ

Avoid reverting to temporary names such as HYRXMQ/HYRX unless required by an external technical identifier.
