# Documentation Status Vocabulary

The following terms are normative for public documentation.

| Status | Meaning |
|---|---|
| Established | Supported by current architectural or semantic evidence. |
| Implemented | Present in the current implementation. |
| Experimental | Implemented but subject to change. |
| Specified | Defined architecturally but not necessarily implemented. |
| Proposed | Intended future architecture. |
| Research | Open investigation. |
| Illustrative | Conceptual example only. |

## Rule

Never infer implementation status from:

- a directory name;
- a Markdown specification;
- a type declaration;
- an architectural diagram;
- a planned provider;
- a public-documentation page.

Implementation claims require implementation evidence.

## Why this matters

SCR deliberately has an architecture that is broader than its current implementation.

The distinction is part of the project's intellectual honesty and should remain visible in public documentation.
